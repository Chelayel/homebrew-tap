# Chelayel Homebrew tap

```bash
brew install chelayel/tap/airelay
brew install --cask chelayel/tap/petabytes
```

Formulae and casks are generated by the release workflow of the corresponding project and
copied here on each release.

| Formula | Project |
| --- | --- |
| `airelay` | [AI Relay](https://github.com/Chelayel/ai-relay) — Claude, Gemini and Copilot as CLI coding agents |
| `petabytes` (cask) | [Petabytes](https://github.com/Chelayel/petabytes) — a coding pet that lives on your Dock and reacts to what you do |
